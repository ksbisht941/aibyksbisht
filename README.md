## Overview

A modern, interactive 3D portfolio showcasing my work as an AI/ML Engineer with 7+ years of experience architecting AI systems for enterprise scale. 
This repository contains the source code for my personal website, featuring smooth animations, dynamic 3D elements, and a responsive design built with Next.js and React Three Fiber.

> [!TIP]
> The portfolio is designed to be highly interactive. Move your mouse around the hero section to see the floating tech stack stickers react to your cursor!

## Features

- 🎯 **Interactive 3D Elements** - Immersive user experience powered by React Three Fiber and Three.js
- ⚡ **Smooth Animations** - High-performance UI transitions and scroll effects using Framer Motion
- 🎨 **Modern Design** - Clean aesthetic built with Tailwind CSS v4 and a customized component system
- 🚀 **Next.js App Router** - Leveraging the latest Next.js features for optimal performance and SEO
- 📱 **Fully Responsive** - Flawless experience across desktop, tablet, and mobile devices

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **UI Library:** [React](https://react.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics:** [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) & [Three.js](https://threejs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Content Rendering:** [React Markdown](https://github.com/remarkjs/react-markdown)

## Getting Started

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v20 or higher recommended)
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ksbisht941/portfolio-2.git
cd portfolio-2
```

2. Install dependencies:
```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Start the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result. You can start editing the page by modifying `src/app/page.tsx`.
